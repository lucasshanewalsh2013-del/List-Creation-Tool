# List-Creation-Tool
Something I made in 2025 for a project. Originally on my old acc, but I am reuploading it here too. Enjoy!<br>
<br>
Usage:<br>
<br>
Hey there! Thanks for downloading my tool! Here's the docs for how to use it!<br>
To begin, here are the list of commands:<br>

create<br>
append<br>
display<br>
quit<br>
<br>
and here are the different list types:<br>
<br>
int (integers)<br>
float (floating point numbers)<br>
bool (booleans)<br>
enum (enumerates)<br>
char (strings/text)<br>
container (contains other lists)<br>
<br>
to use the command "create", you write the command, then the type of list.<br>
<br>
create int<br>
create float<br>
create bool<br>
create enum<br>
create char<br>
create container<br>
<br>
to use append, write the command, and then the name of the list.<br>
<br>
(never append to containers, not implemented yet)<br>
<br>
append int<br>
append float<br>
append bool<br>
append enum<br>
append char<br>
<br>
then you are asked: to what list do you want to append to and what value? you then write the list id (for example: list1, list25, etc), and the value.<br>
<br>
(make sure you append the right value or you'll get an error!)<br>
<br>
list1 <value><br>
list25 <value><br>
etc<br>
<br>
display shows the entire hierarchy of the main container.<br>
container([intlist([25, 56, 63])boollist([true, false, false])])<br>
<br>
quit exits out of the program safely.<br>
<br>
Have fun!
